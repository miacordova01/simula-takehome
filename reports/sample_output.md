### What changes between the two contexts

The ordering is not fixed. Context B is a `mature` character, which removes every advertiser capped at `sfw` before scoring - including `AD_BANK_CARD`, the highest bid in the slate at $5.00. The remaining ads also reorder, because the model's estimate for a given ad moves with the surface, device and character it is being shown against.

The two cold ads carry a visible exploration bonus in both contexts. That bonus is a function of how many impressions the ad has already accumulated, so it decays on its own as data arrives - there is no separate new-ad code path and no graduation threshold to tune.
